# Shared packages (reserved)

Directory reserved for code shared across apps (e.g. shared types, shared config)
**when a real second consumer exists**.

No package is created in Phase 0 on purpose: the guideline is to avoid premature
complexity, and nothing is genuinely shared yet between `apps/web` and `apps/api`.

See ADR-013 (naming conventions) and the Phase 0 continuity documentation.
